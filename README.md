## Как это сделано

Диаграммы строятся кодом (`matplotlib`), презентация собирается скриптом
(`python-pptx`), поэтому цифры и подписи не расходятся между слайдами, PDF и
онлайн-версией. Диаграммы рисуются ровно в том размере, который занимают на
слайде: если масштабировать картинку, вместе с ней уменьшится и текст, а по
требованиям кегль не должен опускаться ниже 16 пт.

Вёрстка проверяется автоматически. Скрипт `audit_pptx.py` сравнивает
нарисованный PDF с координатами блоков в .pptx и сообщает о тексте, который
вылез за границы блока или за поля слайда, и о наложениях объектов. Текущий
результат — 0 замечаний на всех 14 слайдах.

## Соответствие требованиям

| Требование | Как выполнено |
|---|---|
| Титульный слайд: тема, ФИО, организация, email, логотип, дата | Слайд 1 |
| Оглавление | Слайд 2 |
| Не менее одного слайда на логический блок | 6 блоков, 14 слайдов |
| Выводы в конце | Слайд 13 |
| Заключительный слайд | Слайд 14 |
| Заголовок на каждом слайде | Да |
| Нумерация слайдов | Да, все 14 |
| Рубленый шрифт, основной кегль ≥ 16 пт, заголовки ≥ 20 пт | Arial; заголовки 28–44 пт, текст 16–17 пт, подписи на диаграммах 16–19 пт |
| Не более 4 объектов на слайде | Соблюдено |
| Информация тезисами, 2–5 фраз | 2–5 тезисов на слайд |
| Данные в таблицах, схемах, диаграммах | 10 диаграмм, 3 таблицы, 2 схемы |
| Анимация отсутствует | Анимации нет |
| Не читать текст со слайда | Речь докладчика в заметках, объёмнее текста слайда |
| Внимание в первые 20 секунд | Вопрос залу в заметках к слайду 1 |
| Формат .pptx + .pdf | Оба файла в репозитории |

Оформление: светлый фон, тёмный текст, нейтральная гамма и два акцента —
синий для цифровой автоматизации (ИИ), оранжевый для физической (роботы).

```bash
./rebuild.sh
```

## Правка под себя

Данные докладчика вынесены в начало `build_deck.py`:

```python
AUTHOR = "Иванов Иван Иванович"
GROUP  = "Группа ЭК-21, экономический факультет"
ORG    = "Учебная организация"
EMAIL  = "student@example.edu"
EVENT  = "Практическое занятие №10"
DATE   = "15 октября 2026 г."
```

Логотип на титульном слайде — временная монограмма (`assets/charts/01_logo.png`).
Замените файл на логотип организации и пересоберите презентацию.

Цифры взяты из источников, перечисленных в `SOURCES.md`; часть показателей
округлена для устного доклада, прогнозные значения помечены на слайдах.
